### LLD (Approximately 50 minutes)

- Avoid crammed up solutions
- There should be some structure
- Expectation is a meaningful dialogue rather than a complete working solution

### Stages

#### 1. Requirement Gathering (5-10 minutes)

- Focus on exploring each and every angle of the problem statment
- State all possible assumptions before hand
  - Confirm it with the interviewer

- Functional Requirement
  - What the system should do
- Non Functional Requrement(NFR)
  - How the system system should
  - Modular Code
  - Scalable
  - Low Coupling

#### 2. Identifying the entities of the system (5 minutes)

- Identify the nouns / entities of the system
- Generally it would 10-15 in number
- Correlate it with the requirements that you have gathered.
- Think through the major flows of the system.

#### 3. Detail Design of the system (25-30 minutes)

- Go entity by entity
- Identify the attributes of the entitis
- Idenitfy the behaviours of the entitis
- Identify the relationship between entities

- Top to Bottom Approach
- Bottom to Top Approach
- Top: Biggest Class
- Bottom: Smallest Class first

#### 4: Diagrams (5 minutes):

- Draw on Pen and Paper or any other tool like DrawIO

#### 5 Follow up Questions (5-10 minutes)

- Discussions on Design Patterns
- You can discuss missing requirements or an extension to the problem
- Implement a critical behaviour
